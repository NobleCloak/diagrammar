# @noblecloak/diagrammar

Command-line interface for authoring, validating, and rendering Diagrammar
diagrams, and for launching the bundled MCP server.

Install: `bun add -g @noblecloak/diagrammar` (or `npm install -g @noblecloak/diagrammar`)

See the [root README](https://github.com/NobleCloak/diagrammar#readme) for the
full command reference (`new`, `validate`, `describe`, `edit`, `render`, `mcp`).
