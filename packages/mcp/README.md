# @noblecloak/diagrammar-mcp

Streamable HTTP MCP server exposing Diagrammar's create/edit/validate/render
tools and resources, so agents can author and render diagrams by element id
without shelling out to the CLI.

Install: `bun add @noblecloak/diagrammar-mcp` (or `npm install @noblecloak/diagrammar-mcp`)

See the [root README](https://github.com/NobleCloak/diagrammar#readme) for
server setup, the tool list, and `.mcp.json` client configuration.
